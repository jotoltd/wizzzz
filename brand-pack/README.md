# WIZZZ Brand Pack

Everything you need to use the WIZZZ brand consistently.

## What's in here

### `WIZZZ-Brand-Guidelines.pdf`
The full brand guide — logo, colour, typography, usage rules, and asset listing. Send this to anyone who needs to use the brand.

### `logos/`
All logo variants in SVG (vector, scalable) and PNG (raster, for apps that don't take SVG).

| File | Use |
|------|-----|
| `wizzz-wordmark-gradient` | Primary logo. Use everywhere by default. |
| `wizzz-wordmark-white` | Monochrome white. For dark backgrounds and single-colour print. |
| `wizzz-wmark-gradient` | Just the W. For favicons, app icons, avatars. |
| `wizzz-wmark-white` | W mark in white. For dark backgrounds. |
| `wizzz-wordmark-black` | Black wordmark. For light backgrounds in print. |
| `app-icon.svg` / `app-icon-180/512/1024.png` | Square app icon for iOS/Android. W mark on fiery gradient. |
| `favicon-16/32/48.png` | Browser tab icons. |
| `favicon-180.png` | Apple touch icon (home screen). |

PNG sizes: 200, 512, 1024px. App icon: 180, 512, 1024px square.

### `fonts/`

- `SpaceGrotesk-Variable.woff2` — body font (copy, UI)

Both also available from Google Fonts.

### `social-banner-*.svg` / `.png`

- `social-banner-linkedin` — 1584×396 (LinkedIn cover)

Dark variants (pure black, minimal):
- `social-banner-linkedin-dark` — 1584×396

### `sticker.svg` / `sticker.png`
WhatsApp/Telegram sticker. 512×512 with rounded corners, W mark on dark background. Transparent-able.

### `WIZZZ-Letterhead.pdf`
Blank branded letterhead PDF — just the gradient header and footer. Drop into any tool as a background or print and write on it.

### `invoice-template.html`
Dedicated invoice template with all standard fields: invoice number, issue/due dates, line items with qty/rate/amount, subtotal, VAT, total, and payment details. Print to PDF when done.

### `wizzz-colours.css` / `wizzz-colours.json`
Brand colour palette files. CSS variables for web projects, JSON for design tools and scripts. Both contain the full palette with hex and RGB values, plus the gradient definition.

### `WIZZZ-Business-Card.pdf`
Print-ready business card, 85×55mm. Front: gradient wordmark. Back: contact details.

### `email-signature.html`
HTML email signature. Copy the `<table>` into your email client's signature settings.

### `letterhead-template.html`
Branded template for proposals and quotes. Swap the bracketed placeholders, print to PDF. For a blank letterhead PDF, use `WIZZZ-Letterhead.pdf`.

### Root-level favicons
`favicon.ico`, `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon-180.png` — copies of the favicon set at the brand-pack root for easy access.

### `og-image.png` / `.svg`
1200×630 social preview card. Shows when someone links wizzz.co.uk in Slack, LinkedIn, Twitter, WhatsApp, etc.

### `brand-sting.html`
Animated logo reveal. Open in a browser, screen-record for a 2-second video intro.

## Brand basics

- **Name:** WIZZZ (always uppercase, always three Zs)
- **Trading name:** A trading name of Gedker Ltd
- **Email:** hello@wizzz.co.uk
- **Web:** wizzz.co.uk
- **Display font:** Metamorphous
- **Body font:** Space Grotesk
- **Colours:** Ember `#ffb347` → Flame `#ff8a00` → Orange `#ff4d00` → Red `#d6141f`
- **Background:** Ink `#0a0604`
- **Text:** Paper `#fff7f2`

## Rules

1. Always use the official SVG logo files. Don't recreate the wordmark.
2. The gradient flows across the whole word, not per letter.
3. Keep clear space around the logo equal to the height of the W.
4. Never stretch, skew, rotate, recolour, or add effects to the logo.
5. Never use Metamorphous for body copy. It's display only.
6. Minimum logo size: 120px wide (wordmark), 32px (W mark).
