The Logo

The WIZZZ wordmark is the core of the brand. It uses Metamorphous, a gothic display face, with a continuous ember-to-red gradient flowing across the word. The font is embedded in the SVG so it renders identically everywhere.

Primary (gradient)
Monochrome (white)
Monochrome (black)
W Mark (gradient)

Use the gradient version wherever possible. Use white on dark backgrounds or single-colour print. Use black on light print. Use the W mark for favicons, app icons and any space too small for the full wordmark.

Typography

Display — Metamorphous
WE BUILD BOLD THINGS
Google Fonts · Used for headings, logo, and all display type
Body — Space Grotesk
Space Grotesk carries all body copy, UI labels, navigation, and supporting text. It is geometric but warm, and holds its own next to Metamorphous without competing. Weights: 400, 500, 600, 700.
Google Fonts · Used for body, UI, and all non-display text

Never use Metamorphous for body copy. It is a display face only. Never use Space Grotesk for the logo or major headings. The pairing is deliberate.

04

Usage Rules

  1. Always use the official SVG logo files. Do not recreate the wordmark in text or with a different font.
  2. The gradient must flow continuously across the word, not restart inside each letter.
  3. Keep clear space around the logo equal to the height of the W on all sides.
  4. Never stretch, skew, or rotate the logo.
  5. Never change the gradient colours or stop positions.
  6. Never place the gradient logo on a busy background without sufficient contrast. Use the white version instead.
  7. Never add drop shadows, outlines, or effects to the logo.
  8. The W mark is for small spaces only (favicons, app icons, avatars). Do not use it as a primary logo.
  9. Minimum logo size: 120px wide for the wordmark, 32px for the W mark.
  10. WIZZZ is always uppercase. Always with three Zs.
